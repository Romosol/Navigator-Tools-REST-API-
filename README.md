## 📖 Описание программы

Ручная обработка сотен заявок в личном кабинете АИС «Навигатор» отнимает часы рутинного труда: поиск детей по ФИО, сверка дат рождения, выбор учебного года, выбор группы, подтверждение заявок и перевод на этап «Обучение» с вводом номеров приказов.

**NavigatorApp** автоматизирует все эти операции через прямое защищенное взаимодействие с REST API Навигатора (`/api/rest/*`), считывая списки детей из удобных таблиц Excel (`.xlsx`) и записывая актуальные результаты работы обратно в таблицу и детальные текстовые отчеты.

### Основные преимущества:
- **Высокая скорость**: пакетная обработка десятков и сотен заявок за считанные секунды с умными паузами между запросами.
- **Интеллектуальная валидация**: сверка ФИО (с поддержкой буквы «ё»), строгая проверка соответствия даты рождения ребенка в базе, защита от повторных записей (дубликатов).
- **Двусторонняя синхронизация с Excel**: программа не только читает списки, но и в реальном времени проставляет статус («Зачислен», номер созданной заявки ID, дату) прямо в столбцы Excel.
- **Поддержка истории ввода**: все поля сохраняют историю последних использованных значений в выпадающие списки (`Combobox`) по клику мыши.
- **Удобный русскоязычный графический интерфейс (GUI)**: нативная тема Windows/Linux, вкладки, журнальная консоль с цветным выводом, горячие клавиши вставки/копирования (`Ctrl+C`, `Ctrl+V`).

## ⚡ Ключевые возможности

| Раздел | Функционал | Используемый API / файл |
| :--- | :--- | :--- |
| **Вход в систему** | Авторизация методиста/администратора, сохранение сессии и истории логинов | `POST /api/user/login` |
| **1. Запись на мероприятие** | Массовая подача заявок на разовые мастер-классы, интенсивы, фестивали | `event_list.xlsx`<br>`POST /api/rest/activityOrder` |
| **2. Подтверждение и участие** | Просмотр неподтвержденных заявок на мероприятие, массовый перевод в статус «Подтверждено» (`approve`) и «Участник» (`participant`) | `POST /api/setActivityOrderState` |

## 📦 Состав релизной версии

Свежие сборки приложения публикуются на странице: **[GitHub Releases](https://github.com/Romosol/Navigator-Tools-REST-API-/releases)**.

Для начала работы достаточно скачать единственный файл **`NavigatorApp.exe`** и поместить его в отдельную папку (например, `C:\NavigatorApp\`).

При первом запуске приложение **автоматически создаст**:
- `config.json` — конфигурационный файл с настройками по умолчанию;
- Все шаблоны таблиц Excel (`event_list.xlsx`, `programm_list.xlsx`, `study_list.xlsx`) с корректными заголовками и форматированием;
- Папку `logs/` для сохранения детальных отчетов работы.

Структура рабочей папки приложения:

```text
NavigatorApp/
├── NavigatorApp.exe           # Исполняемый файл приложения (для Windows)
├── app.ico                    # Иконка программы (встроена в EXE)
├── config.json                # Файл конфигурации (сохраненные параметры, история полей)
├── config.example.json        # Пример конфигурации для разработчиков
├── event_list.xlsx            # Таблица-шаблон для Вкладки 1 (Запись на мероприятия)
├── programm_list.xlsx         # Таблица-шаблон для Вкладки 3 (Зачисление на программы)
├── study_list.xlsx            # Таблица-шаблон для Вкладки 4 (Сверка со списком зачисления)
├── LICENSE                    # Лицензия MIT
└── logs/                      # Папка журналов операций (создается автоматически)
    ├── results_log.txt        # Сводный журнал последней сессии
    └── results_log_*.txt      # Детальные архивы каждой отдельной сессии
```

### Назначение файлов:
1. **`event_list.xlsx`** (3 столбца):
   - Столбец A: `ФИО` (например: *Иванов Иван Иванович*)
   - Столбец B: `Дата рождения` (например: *15.03.2012*)
   - Столбец C: `Статус` (программа сама записывает результат обработки)
2. **`programm_list.xlsx`** (3 столбца):
   - Столбец A: `ФИО`
   - Столбец B: `Дата рождения`
   - Столбец C: `Статус` (заполняется статусом создания заявки в Навигаторе, номером ID)
3. **`study_list.xlsx`** (2 столбца):
   - Столбец A: `ФИО`
   - Столбец B: `Флаг зачисления` (любая отметка: `1`, `да`, `зачислить`, `+`)
4. **`config.json`**:
   - Хранит логин, сохраненные названия программ, групп, приказов, флаги чекбоксов и историю ранее введенных значений. Исключен из Git в `.gitignore` в целях безопасности.
5. **`config.example.json`**:
   - Обезличенный шаблон конфигурации. Если вы клонировали репозиторий, можете скопировать его как `config.json`.

## 💻 Системные требования и зависимости

### Поддерживаемые операционные системы:
- **Windows 10 / 11** (полная поддержка сборки EXE и запуска скрипта)
- **Linux** (Ubuntu 20.04+, Debian, Fedora, Arch Linux)
- **macOS** (10.15 Catalina и новее)

### Программное обеспечение:
- **Python** версии **3.8 — 3.12+** (при запуске из исходного кода).  
  *При установке Python на Windows обязательно отметьте галочку: **«Add Python to PATH»**.*
- Наличие графической подсистемы **Tkinter** (входит в стандартную поставку Python для Windows; на Linux устанавливается пакетом `python3-tk`).
- Офисный пакет (Microsoft Excel, LibreOffice Calc, МойОфис) для просмотра и редактирования файлов `.xlsx`.

### Внешние Python-библиотеки (`requirements.txt`):
```text
requests>=2.28.0    # Выполнение защищенных HTTP/HTTPS запросов к API Навигатора
openpyxl>=3.1.0     # Чтение и потоковая запись в файлы Excel .xlsx
pyinstaller>=6.0.0  # (Опционально) сборка автономного .exe файла
```

## 🚀 Установка и запуск через Python / Терминал

### Шаг 1. Клонирование репозитория или загрузка архива
```bash
git clone https://github.com/your-username/navigator-automation.git
cd navigator-automation
```
*Либо скачайте ZIP-архив репозитория и распакуйте в любую удобную папку.*

### Шаг 2. Создание и активация виртуального окружения (рекомендуется)

**В Windows (Командная строка CMD или PowerShell):**
```cmd
python -m venv venv
venv\Scripts\activate
```

**В Linux / macOS:**
```bash
python3 -m venv venv
source venv/bin/activate
```

### Шаг 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

> **Примечание для пользователей Linux (Ubuntu / Debian):**  
> Если при запуске возникает ошибка `No module named 'tkinter'`, установите пакет Tkinter:
> ```bash
> sudo apt-get update && sudo apt-get install -y python3-tk
> ```

### Шаг 4. Запуск приложения
**В Windows:**
```cmd
python navigator_app.py
```

**В Linux / macOS:**
```bash
python3 navigator_app.py
```

## 🔨 Сборка автономного EXE (Windows)

Если вам требуется запустить программу на компьютерах, где **не установлен Python**, соберите автономный исполняемый `.exe` файл.

### Способ 1. Автоматическая сборка в один клик
Просто дважды кликните по файлу **`build_exe.bat`**.  
Скрипт автоматически:
1. Проверит и установит нужные библиотеки.
2. Соберет через PyInstaller один сжатый файл `NavigatorApp.exe`.
3. Создаст каталог `dist/` и скопирует туда шаблоны `event_list.xlsx`, `programm_list.xlsx`, `study_list.xlsx`, `config.json` и папку `logs/`.

### Способ 2. Ручная сборка через терминал
```cmd
pip install pyinstaller -r requirements.txt
pyinstaller --noconsole --onefile --name "NavigatorApp" navigator_app.py
```
После завершения скопируйте файлы `*.xlsx` и `config.json` в папку `dist/` рядом с `NavigatorApp.exe`.

## 📚 Подробная инструкция по работе

### 1. Авторизация
1. При первом запуске откроется окно авторизации в АИС «Навигатор».
2. Введите ваш **Email / Логин** и **Пароль** от личного кабинета учреждения в Навигаторе.
3. Поставьте галочку **«Сохранить пароль на этом ПК»** (пароль будет сохранен локально в `config.json`).
4. Нажмите кнопку **«Войти в систему»**.
5. Поле логина запоминает историю ввода — при повторном входе можно кликнуть по нему и выбрать адрес из списка.

---

### 2. Вкладка 1: Пакетная запись на мероприятие (`event_list.xlsx`)
Используется для массовой регистрации детей на мастер-классы, дни открытых дверей, разовые мероприятия:

1. Заполните файл **`event_list.xlsx`** (ФИО и дата рождения).
2. В поле **«Название мероприятия»** введите название или выберите его из истории по клику на поле.
3. Нажмите кнопку **«Проверить инфо о мероприятии»** — программа найдет мероприятие в Навигаторе, проверит статус записи, дату и выведет его ID.
4. В поле **«Дата и время заявки»** укажите дату в формате `ГГГГ-ММ-ДД ЧЧ:ММ:СС` (или выберите из истории).
5. Нажмите **«▶ Запустить пакетную запись»**.
6. Ход обработки отображается в журнале в реальном времени. По окончании статус каждого ребенка будет сохранен в третьем столбце таблицы Excel.

---

### 3. Вкладка 2: Подтверждение и участие в мероприятии
Используется для перевода поданных заявок в подтвержденные и отметки фактического участия:

1. Выберите название мероприятия (или кликните по полю для выбора из истории).
2. Нажмите **«Найти неподтвержденные заявки»**: программа свяжется с API и отобразит количество заявок в статусах `initial`, `approve`, `participant`.
3. Для подтверждения нажмите:
   - **«✔ Подтвердить все неподтвержденные заявки»** (`initial ➜ approve`).
4. Для отметки участия детей нажмите:
   - **«🎓 Отметить всех подтвержденных как участников»** (`approve ➜ participant`).

---

### 4. Вкладка 3: Зачисление на учебную программу (`programm_list.xlsx`)
Основной режим формирования заявок на долгосрочные программы дополнительного образования:

1. Подготовьте файл **`programm_list.xlsx`** со списком детей (ФИО, дата рождения в формате `ДД.ММ.ГГГГ`).
2. Введите или выберите из истории:
   - **Название программы** (поиск регистронезависимый, можно вводить ключевые слова).
   - **Название или ID группы** (например: *«Группа 1»* или *67890*).
   - **Учебный год** (например: `2026/2027` или `2026`).
3. Настройте параметры сертификатов:
   - `Создавать сертификат`: создается автоматически, если у ребенка его еще нет.
   - `Использовать сертификат`: привязка сертификата учета/финансирования.
4. Нажмите кнопки **«Найти программу»** и **«Проверить группу»** для подтверждения параметров.
5. Нажмите **«▶ Начать зачисление на программу»**.
6. **Защита от дубликатов**: если ребенок уже зачислен в данную группу в Навигаторе (статус `study` или `approve`), программа безопасно пропустит его, не создавая дублирующую заявку, и отметит это в журнале и таблице Excel.

---

### 5. Вкладка 4: Сверка со `study_list.xlsx`, подтверждение и обучение
Используется для перевода принятых детей в статус «Обучается» с фиксацией приказа о зачислении:

1. В файл **`study_list.xlsx`** поместите список детей (Столбец A — ФИО, Столбец B — отметка о зачислении).
2. В интерфейсе укажите:
   - Название программы, группы и учебного года.
   - **№ приказа** (например: `183`).
   - **Дата приказа** (например: `31.08.2026`).
   - **Дата начала обучения** (например: `01.09.2026`).
3. Нажмите **«🔎 Загрузить список заявок программы»**: программа скачает текущие заявки из Навигатора и сопоставит их с вашим списком `study_list.xlsx`.
4. Нажмите **«🚀 Выполнить ВСЁ (Шаг 1 + Шаг 2)»**:
   - **Шаг 1**: заявки из списка переводятся в статус «Подтверждена» (`approve`).
   - **Шаг 2**: подтвержденные заявки переводятся в статус «Обучается» (`study`) с указанием номера и даты приказа.
   - В файле `study_list.xlsx` проставляется флаг: `Зачислен`.

---

### 6. История полей и выпадающие списки
- Каждое ключевое поле ввода (название программы, группа, год, реквизиты приказа, мероприятие, логин) снабжено автоматической историей.
- **Как открыть**: просто **кликните левой кнопкой мыши по самому полю** или нажмите клавишу **↓ (Стрелка вниз)** на клавиатуре.
- Значения упорядочены по времени использования (наверху списка — самые свежие).
- История хранится в файле `config.json` в секции `"history"`.

---

### 7. Экстренная остановка операций
- В верхней части рабочей области расположена яркая кнопка **«🛑 ОСТАНОВИТЬ ОПЕРАЦИЮ»**.
- Если вы запустили пакетную обработку и заметили ошибку во входных данных, нажмите эту кнопку: текущий запрос корректно завершится, а последующие записи будут немедленно остановлены без повреждения структуры Excel.

---

### 8. Журналы и логирование
- Все отчеты сохраняются **исключительно в директории `logs/`**. Корневая папка проекта остается чистой.
- При каждом старте создается уникальный файл вида:  
  `logs/results_log_ГГГГ-ММ-ДД_ЧЧ-ММ-СС.txt`
- Актуальный срез последней операции также дублируется в `logs/results_log.txt`.
- Быстрый доступ:
  - Кнопка **«📋 Лог»** в шапке приложения мгновенно открывает журнал текущей сессии в Блокноте.
  - Кнопка **«📁 Папка логов»** открывает папку `logs/` в проводнике Windows.

---

### 9. Проверка новых релизов и обновления
- При старте `NavigatorApp` автоматически отправляет легковесный асинхронный запрос к GitHub API (`https://api.github.com/repos/Romosol/Navigator-Tools-REST-API-/releases/latest`).
- Проверка выполняется **в отдельном фоновом потоке**, поэтому интерфейс не зависает даже при отсутствии или медленном интернете.
- Если на GitHub опубликован более свежий релиз (например, `v2.2` при установленной `v2.1`), программа открывает информационное окно:
  - Показывает номер новой версии и краткое описание изменений;
  - Предлагает кнопку **«📥 Скачать обновление (Открыть GitHub)»**, которая открывает страницу релиза в браузере;
  - Кнопку **«Напомнить позже»** для откладывания;
  - Чекбокс для включения/отключения автопроверки (сохраняется в `config.json` как `"check_updates": true/false`).
- В любое время проверить обновления можно вручную: нажатием кнопки **«🔄 Проверить обновления»** на экране входа или в верхней панели управления.

### 10. Формирование версий и автоматическая синхронизация тегов с EXE

Проект следует общепринятому стандарту семантического версионирования **SemVer** (`v[МАЖОРНАЯ].[МИНОРНАЯ].[ПАТЧ]`):

- **Патч (`2.1.1`, `2.1.2`)**: небольшие исправления багов или доработки без изменения базовой логики.
- **Минорная (`2.2.0`, `2.3.0`)**: добавление новых функций, вкладок или значительных оптимизаций.
- **Мажорная (`3.0.0`)**: глобальное обновление или смена архитектуры.

#### Почему `v2.0.1` считался старее `v2.1.0`?
Сравнение версий идёт слева направо по цифрам:
- Версия в приложении: `2 . 1 . 0`
- Тег на GitHub: `2 . 0 . 1`  
Поскольку `1` во второй позиции больше `0`, программа справедливо определяет, что текущая `2.1.0` новее, чем `2.0.1`. Поэтому для следующего релиза следует выбирать тег **`v2.1.1`** (для патча) или **`v2.2.0`** (для следующего релиза).

#### Автоматическая подстановка версии в EXE (GitHub Actions):
В репозитории настроен рабочий процесс (`.github/workflows/build-exe.yml`):
- При создании любого тега или публикации релиза на GitHub (например, `v2.1.1`, `v2.2.0`):
  1. GitHub Actions извлекает номер версии из имени тега (`v2.1.1` → `2.1.1`);
  2. Автоматически внедряет значение `APP_VERSION = "2.1.1"` внутрь `navigator_app.py`;
  3. Собирает `NavigatorApp.exe` через PyInstaller;
  4. Прикрепляет готовый `.exe` прямо к релизу.
Вам больше **не нужно вручную менять код программы** перед выпуском релиза — просто создайте тег, и билд автоматически получит идентичную версию!

## ❓ Возможные проблемы и способы их решения

### 1. `NameError: name 'Callable' is not defined`
- **Причина**: В старой версии билда отсутствовал импорт `Callable` из стандартного модуля `typing`.
- **Решение**: Проблема устранена. Загрузите обновленный `navigator_app.py` или пересоберите `.exe` файл запуском `build_exe.bat`.

### 2. `ModuleNotFoundError: No module named 'requests'` (или `openpyxl`)
- **Причина**: Не установлены сторонние библиотеки Python.
- **Решение**: Выполните в терминале команду:
  ```bash
  pip install requests openpyxl
  ```
  Если используете виртуальное окружение, убедитесь, что оно активировано.

### 2. `PermissionError: [Errno 13] Permission denied: 'programm_list.xlsx'`
- **Причина**: Файл таблицы в этот момент открыт в Microsoft Excel. Excel блокирует редактирование файла другими процессами.
- **Решение**: Сохраните и закройте файл таблицы в Excel, затем повторите операцию в NavigatorApp.

### 3. «Ошибка авторизации: Неверный логин или пароль»
- **Причина**: Опечатка в логине/пароле или учетная запись не имеет прав администратора/методиста в региональной АИС «Навигатор».
- **Решение**: Проверьте возможность входа под этой же учетной записью через обычный браузер. Обратите внимание на раскладку клавиатуры и Caps Lock.

### 4. Предупреждение: «ДР не совпала» при зачислении ребенка
- **Причина**: Дата рождения в таблице Excel отличается от даты, внесенной родителями в профиль ребенка в Навигаторе.
- **Решение**: Программа защищает от ошибочной записи тезок и однофамильцев. Проверьте свидетельство о рождении ребенка или скорректируйте дату в Excel-таблице. Допустимый формат: `ДД.ММ.ГГГГ` (например: `10.05.2012`).

### 5. «Программа не найдена» или «Группа не найдена»
- **Причина**: Название введено неточно или программа находится в архиве/черновике.
- **Решение**: Вводите название частично (например, *Основы программирования*) либо укажите точный цифровой ID группы (например, *67890*). Нажмите кнопку «Найти программу» для предварительной проверки.

### 6. Проблема с отображением шрифтов или мелкий интерфейс на 4K-мониторах
- **Причина**: Высокое масштабирование экрана Windows (DPI Scaling 125%, 150%).
- **Решение**: В код приложения уже встроена автоматическая компенсация системного DPI через WinAPI (`GetDeviceCaps`). Интерфейс автоматически масштабирует размер шрифтов под разрешение вашего монитора.

## 🔒 Безопасность данных

1. **Локальное хранение**: Все пароли, параметры и логи хранятся исключительно на вашем локальном компьютере в файлах `config.json` и каталоге `logs/`.
2. **Прямое соединение**: Приложение взаимодействует **напрямую** с официальным защищенным сервером АИС «Навигатор» по протоколу HTTPS. Никакие промежуточные сторонние сервера не используются.
3. **Безопасность таблиц**: При записи результатов в таблицы Excel формулы и форматирование исходных строк не повреждаются.
